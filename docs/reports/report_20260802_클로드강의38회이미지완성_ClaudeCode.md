- 대상: 《클로드 기초 및 활용》 4~38회 Ghost 발행글

## 1. 결과

**4~38회 전 35편의 `[이미지 추후 생성]` 플레이스홀더가 모두 실제 이미지로 교체 완료.** 잔여 플레이스홀더 0.

두 세션이 동시에 진행했고 분담은 다음과 같다.

| 구간 | 담당 |
|---|---|
| 4~12회, 14~25회 | 다른 세션 |
| 13회, 26~38회 (14편) | 본 세션 |

본 세션 산출: 이미지 **152장** (생성 165장 중 반려 13장 제외).

## 2. 본 세션 작업 방식

1. `ghost_get_post`로 원문 확보 → `prep.py`로 플레이스홀더 위치와 직전 h2 추출
2. 각 자리의 개념에 맞는 프롬프트 작성 → `svil_generate_image` (zimage, steps 8, cfg 1, 1280×720)
3. `ffmpeg tile=4x3` 컨택트시트 1장으로 일괄 육안 검수
4. 반려분 재생성 후 재검수
5. Ghost 업로드 → `patch.py`로 플레이스홀더를 `kg-image-card`로 치환
6. `ghost_update_post` 전문 교체 + feature_image 지정
7. `C:\youtube\asset\img\CLAUDE1{회차}_{KEYWORD}_01.png` 로 자산 등록

alt 텍스트는 전부 한국어 개념 서술형("~을 표현한 개념 이미지")으로 작성했다.

## 3. 반려 13장의 사유

| 사유 | 건수 | 사례 |
|---|---|---|
| 사람 형상 | 6 | 손 2, 얼굴 옆모습 1(3연), 인체 1, 앉은 사람 1, 손가락형 갈퀴 1 |
| 텍스트·기호 렌더 | 5 | 라벨 글자, 물음표, 숫자 "1", 비상구 픽토그램, 문서 텍스트 패턴 |
| 대비 부족 | 1 | 격자 지형이 거의 검게 뭉개짐 |
| 개념 불일치 | 1 | "끊긴 선"이 이어진 선으로 렌더 |

표로 못 보는 환경을 위해 문장으로도 적는다. **반려 13장 중 사람 형상이 6건으로 가장 많았고, 텍스트·기호가 5건, 대비 부족과 개념 불일치가 각 1건이었다.**

## 4. 새로 확인된 트랩 워드

기존 목록(`note` `plane` `seal` `transformer` `gauge` `constellation` 등)에 추가한다.

| 단어·표현 | 유발되는 것 | 치환 |
|---|---|---|
| `form`, `shape` | 사람 얼굴·인체 | `monolith`, `cube`, `crystal shard` |
| `held side by side`, `holding` | 사람 손 | `standing side by side`, `resting on` |
| `casting mold` | 손바닥 형태 | `rectangular vessel` |
| `tag`, `label`, `sheet of paper` | 글자 각인 | `blank metal plate`, `folded metal sheet` |
| `exit route` | 비상구 픽토그램(사람) | `bright open rectangle of light` |
| `inert`, `nothing happening` | 앉아 있는 사람 | `dim static indicator` |

문장으로도 적는다. **`form`과 `shape`은 사람 얼굴이나 인체를 부르므로 구체 사물명으로 바꾼다. `holding`이나 `held`가 들어가면 손이 나온다. `mold`는 손바닥이 되고, `tag`·`label`·`paper`는 글자를 부른다. `exit`는 비상구 픽토그램(사람 형상)을 만든다.**

neg_prompt 추가 항목: `hand, finger, palm, head, profile, chair, seat, label, engraving, digit, numeral, question mark, waveform, sign, pictogram`.

## 6. 남은 사항 (사용자 판단 필요)

### 6-1. 4·5회차 중복 발행 — 해소 확인 (삭제 대상 없음)

커리큘럼 문서 §15에 "중복 2건 대기" 기록이 있었으나 **이미 해소된 상태였다.**

"중복은 삭제" 지시를 받고 `ghost_list_posts`로 시리즈 전체를 조회한 결과 **총 38건, 1~38회가 각 1건씩**이었다. 플레이스홀더 판본(`…071f`, `…0735`)은 남아 있지 않다.

| 회차 | 현존 판본 | 상태 |
|---|---|---|
| 4회 | `6a6e6f384c2dac0001ae072a` | 이미지 16장 완비 |
| 5회 | `6a6e8b1b4c2dac0001ae08e5` | 이미지 17장 완비 |

문장으로도 적는다. **4회차는 `…072a` 한 건, 5회차는 `…08e5` 한 건만 남아 있고 둘 다 이미지가 채워져 있다.** 삭제 대상이 없어 아무것도 삭제하지 않았다. 삭제는 되돌릴 수 없으므로 목록 확인을 선행한 판단이다.

### 6-2. ComfyUI 종료 안 함

세션 시작 시 이미 가동 중이었고 다른 세션과 공유 중이라 종료하지 않았다. 메모리 규칙 "내가 올린 것만 내린다"에 따른 판단이다. 두 세션이 모두 끝났다면 종료해도 된다.
