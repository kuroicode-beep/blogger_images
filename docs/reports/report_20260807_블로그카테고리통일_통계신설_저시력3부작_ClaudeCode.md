## 5. 🔴 ComfyUI NaN — 근본 원인 규명

이미지가 **검정(4KB)** 또는 **컬러 노이즈(1.7MB대)** 로 나오던 문제. 드라이버·프롬프트 문제가 아니라 **VRAM 부족**이었다.

ComfyUI가 Z-Image를 **fp8 5,869MB** 또는 **bf16 11,738MB** 중 하나로 로드하는데, 로드 시점 여유를 보고 bf16을 골라 놓고 실제로는 다 못 올리면 **VAE 디코드가 NaN을 뱉는다.** 그런데 에러가 안 난다 — 샘플러는 `8/8` 정상 완주하고 `Prompt executed`까지 찍히며, 로그에는 `nodes.py:1682: RuntimeWarning: invalid value encountered in cast` 한 줄만 남는다.

- **판별법**: 파일 크기. ~4KB=검정 / 1.5MB↑=노이즈 / 600KB~1.1MB=정상
- **대처**: `svil_comfy_free`로는 안 된다(실측 회수량 0.27GB, 심지어 −0.17GB). **프로세스 재기동**이 유일. 여유 10GB에서 시작 → 계속 검정 / 여유 15.6GB에서 시작 → 66장 연속 정상
- **병렬 큐잉 금지**: 한 메시지에서 여러 장을 동시 호출하면 전부 타임아웃 나고 큐에도 안 들어가며, 그중 하나가 **VRAM 락을 쥔 채 죽는다**(실측 `held_sec 645`). `svil_vram_force_release`로 풀어야 한다
