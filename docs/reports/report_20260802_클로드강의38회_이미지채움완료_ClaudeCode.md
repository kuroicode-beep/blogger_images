## 4. 새로 확인한 프롬프트 함정

Z-Image Turbo는 cfg 1.0 고정이라 negative prompt가 물리적으로 무시된다.
"~하지 마라"가 아니라 **어휘 자체를 바꾸는** 방식으로만 회피 가능하다.

| 단어 | 실제로 나온 것 | 대체어 |
|---|---|---|
| `branches` | 검은 나뭇가지 | `straight slender rods` |
| `splitting into two` | 가시 달린 번개 모양 | `divides into two straight strips` |
| `in order from smallest to largest` | 막대그래프 | `slotted into its own groove` |

기존 함정표(`plate`→접시, `marker`→마커펜, `shape`→실사 사람 손, `key`→실사 열쇠,
`question`→물음표 글자, `tablet`→알약, `sign`→영문 안내판)는
`C:\youtube\docs\가이드_20260731_블로그이미지규칙_ClaudeCode.md`에 누적돼 있다.

## 5. 확립된 절차

1. `ghost_get_post` → 결과가 커서 tool-results 파일로 자동 저장. **본문을 컨텍스트에 올리지 않는다.**
2. `scan.py`(플레이스홀더별 직전 h2) / `layout.py`(h2별 이미지 유무 — 보충 작업용)로 구조만 추출
3. 섹션 주제에 맞는 영어 프롬프트 → `svil_generate_image`(engine `zimage`, 1280×720)
4. ffmpeg 컨택트시트 1장으로 일괄 검수 — 개별 확인보다 반려 검출률이 크게 높다
5. 반려분만 `b` 접미사로 재생성
6. `ghost_upload_image` 일괄 업로드
7. 대체텍스트 표 작성(파일명 TAB 한국어 alt, 본문 등장 순서)
8. `fillgen.py`(플레이스홀더 치환) 또는 `insert.py`(기존 글 보충 삽입)
9. 결과 파일 Read → `ghost_update_post`
10. `C:\youtube\asset\img\`에 `CLAUDE1NN_KEYWORD_01.png`으로 복사

**전수 감사는 `sitemap-posts.xml`에서 URL을 뽑아 curl로 도는 편이 싸다.**
MCP `ghost_get_post`를 38번 부르는 것보다 컨텍스트를 훨씬 아낀다.
